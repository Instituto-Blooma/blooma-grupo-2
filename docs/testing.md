# Tests

Do not add tests to this repository.

Unit tests, Cypress, and end-to-end tests are not part of this project, and creating them is not advised. These apps are hackathon templates: keep changes small, check behavior by running the app, and use `pnpm run check` for format, lint, and types.

`convex/testing/e2e.ts` only seeds local development users during `pnpm run setup`. It is not a test suite. Do not extend it with specs.
